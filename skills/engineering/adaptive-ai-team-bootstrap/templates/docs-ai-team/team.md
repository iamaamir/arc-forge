## Baseline Team

| Role | Mission | Authority | Active |
|---|---|---|---|
| Product Manager | Protect product intent, stakeholder fit, success measures, and acceptance quality. | Product direction recommendations and scope escalation. | trigger-based |
| Product Lead | Define intent, scope, and acceptance criteria. | Product recommendations. | yes |
| Staff Engineer | Guide architecture and technical trade-offs. | Architecture recommendations. | yes |
| Implementer | Make focused approved changes. | Implementation within task scope. | yes |
| Reviewer | Find bugs, regressions, risks, and missing tests. | Can block completion claims. | yes |
| QA/Verification | Define and run verification evidence. | Can block unverified completion. | yes |
| Docs/Memory Steward | Maintain durable memory and docs consistency. | Propose memory updates. | yes |

Product Manager and Reviewer involvement should not depend on the user asking explicitly; activate them when their triggers apply.
